# Surface brief: extension popup, settings, first-run (extension/src/popup/popup.html)

Mode: Operate. Task: turn reminders on/off, choose a frequency, open settings (quiet hours, notification style, randomize). States: first install, OFF, ON, reminder active, quiet hours, custom interval, settings, notification preview, reduced motion, permission denied. Frequency: opened a few times a week for seconds. Constraint: 320-360px wide; a finished sticker, not a shrunken page.

## Direction contract

THESIS: The popup is one sticker: emblem, phrase, two controls. It refues the settings-dashboard arrangement.

OWN-WORLD: Same as the landing page: cream paper, one ink stroke, Eczar + Mukta, sage for quiet hours only. A hand-drawn sticker edge frames the popup; the emblem is the only illustration.

STORY: Click the icon, see the emblem breathe, read the phrase, flip reminders on, close. Done in three seconds.

FIRST VIEWPORT: Emblem centred at the top (about 120px), "Watch your breath." beneath it in Eczar, a short flow line, then the Reminders toggle row and the frequency select row, a small settings glyph bottom-right. Settings slides in as a second view in the same frame.

FORM: Brief-pinned reference sticker. Seed key 6db68fcb.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
